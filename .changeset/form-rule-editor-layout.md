Form settings: the conditions of a question are edited in "Edit conditions", a centered dialog (a bottom drawer on phones) with room for the rules, while the side panel keeps the summary and the button. Each condition is a card that stacks question, comparison and value in narrow containers and lines them up when there is room; comparisons use short complete labels ("is", "is not", "before", "between", "in the last"…, overridable with `form.cmp*`); values use the table's controls (option tags, calendar, number input); a nested group is an indented card with an All/Any segmented control; problems are linked to the control they concern. Same behavior in React and Vue.

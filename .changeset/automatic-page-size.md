Add opt-in automatic page sizing with `table.enableAutoPageSize` in React and Vue. The table's page-size selector can fit rows to the available viewport, react to density and window-size changes, and return to numeric sizes. Pagination remains reachable for a single page when enabled. Gallery and Kanban keep numeric pagination; URLs and saved views continue to store the effective numeric size.

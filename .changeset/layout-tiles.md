The display mode is now chosen as in Notion, in the view menu and the view settings, in React and Vue: a "Display mode" row showing the current mode opens a screen of layout tiles, three per row, the mode's icon over its name, the current one marked. Wide screens used to show a dropdown, which hid the available layouts behind a click; touch drawers already had buttons and now get the same tiles.

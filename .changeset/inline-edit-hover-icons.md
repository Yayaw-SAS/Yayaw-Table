Inline-editable cells now start editing on a single click anywhere in the cell, show a pointer cursor, and show a hover icon named after their editor (pencil, chevron, checklist, tag, `#`, calendar, link, pin, braces) in a small chip floating over the cell's end, so the cell never resizes. Boolean cells show no icon. React and Vue, with the shared `inlineEditorIcon` contract.

# YaYaw Table

A flexible, powerful data table component library for React that lets **you define your own table configurations** instead of imposing predefined structures.

## Philosophy

**No assumptions, full control.** This library doesn't assume your data structure or impose table configurations. You provide both the configuration and data, giving you complete flexibility to create any table you need.

## Features

- 🎛️ **User-Defined Configurations**: Create your own table definitions
- 🏗️ **Flexible Column Types**: text, number, tag, date, boolean, code, dynamicType
- 📱 **Responsive Design**: Mobile-first with horizontal scrolling
- 🎨 **Beautiful UI**: Tailwind CSS + Radix UI components
- ♿ **Accessible**: Full keyboard navigation and screen reader support
- 🔧 **TypeScript**: Fully typed with excellent IntelliSense
- 📦 **Small Bundle**: Only includes what you use
- 🚀 **Performance**: Built on @tanstack/react-table

## Why YaYaw Table?

### ✅ Benefits

- **🎯 No Assumptions**: We don't assume your data structure
- **🔧 Full Control**: You define exactly how your tables work
- **📦 Smaller Bundle**: No unused table configurations
- **🚀 Flexible**: Create any table type you need
- **🏗️ Scalable**: Add new tables without updating the library
- **🛡️ Type Safe**: Full TypeScript support with excellent IntelliSense

### ❌ What We Don't Do

- Impose predefined table structures
- Include configurations you don't need
- Make assumptions about your backend
- Force specific styling or themes
- Require heavy dependencies for basic features

## Quick Preview

```tsx
import { DataTable, defineTableConfig } from 'yayaw-table'

// 1. Define your table configuration
const productsConfig = defineTableConfig({
  id: "products",
  columns: {
    definitions: [
      { id: "name", type: "text", header: "Product Name" },
      { id: "price", type: "number", header: "Price" },
      { id: "status", type: "tag", header: "Status" }
    ],
    order: ["select", "name", "price", "status", "actions"],
    visible: ["select", "name", "price", "status", "actions"]
  },
  table: { defaultPageSize: 10 }
})

// 2. Use with your data
<DataTable 
  tableType="products"
  config={productsConfig}
  data={products}
/>
```

# Guide de migration

## De QueryClient implicite vers un provider partagé explicite

Cette version supprime la création implicite de QueryClient à l'intérieur de YaYaw Table.

## Breaking changes

1. **Plus de fallback QueryClient interne**
   - Avant : `DataTable` pouvait créer un client automatiquement.
   - Maintenant : un QueryClient partagé est requis.
2. **Détection de clients dupliqués**
   - Passer `queryClient` alors qu'un autre client provider existe déclenche maintenant une erreur.
3. **Contrat callback bulk (recommandé)**
   - Utilisez un `BulkActionResult` explicite pour éviter les branches ambiguës.

## Avant / Après

### Avant (comportement implicite)

```tsx
import { QueryClient } from "@tanstack/react-query";
import { DataTable } from "@/components/ui/yayaw-table";

const queryClient = new QueryClient();

export default function ProductsPage() {
  return (
    <DataTable
      tableType="products"
      getTableConfig={getTableConfig}
      getTableActions={getTableActions}
      queryClient={queryClient}
    />
  );
}
```

### Après (provider partagé explicite)

```tsx
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { DataTable } from "@/components/ui/yayaw-table";

const queryClient = new QueryClient();

export default function ProductsPage() {
  return (
    <QueryClientProvider client={queryClient}>
      <DataTable
        tableType="products"
        getTableConfig={getTableConfig}
        getTableActions={getTableActions}
      />
    </QueryClientProvider>
  );
}
```

## Comment migrer en 5 minutes

1. Créez un `QueryClient` unique au niveau app.
2. Encapsulez votre app/page avec `QueryClientProvider`.
3. Supprimez toute hypothèse selon laquelle YaYaw Table crée un client en interne.
4. Assurez-vous que toutes les invalidations custom ciblent `["tableData", tableId]`.
5. (Recommandé) retournez un `BulkActionResult` explicite depuis `onBulkDelete`, `onBulkCopy`, `onBulkEdit`, `onBulkExport`.

```ts
type BulkActionResult = {
  success: boolean;
  closeMenu: boolean;
  clearSelection: boolean;
  message?: string;
};
```

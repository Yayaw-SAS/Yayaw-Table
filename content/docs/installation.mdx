# Installation

Install YaYaw Table in your React project using your preferred package manager.

## Package Manager

```bash title="Using npm"
npm install yayaw-table
```

```bash title="Using Bun (recommended)"
bun add yayaw-table
```

```bash title="Using pnpm"
pnpm add yayaw-table
```

## Peer Dependencies

YaYaw Table relies on the following peer dependencies:

- `react` (^18 or ^19)
- `react-dom` (^18 or ^19)
- `@tanstack/react-table` (^8)
- `jotai` (^2) [optional]
- `@tanstack/react-query` (^5) [optional]

Make sure they are installed in your project.

## First usage

```tsx
import { DataTable } from 'yayaw-table';

export const MyTable = () => (
  <DataTable tableType="products" />
);
```

## CSS/Tailwind

The table uses Tailwind CSS. Ensure Tailwind is set up in your project:

```bash
npm install tailwindcss
```

Or use your own CSS classes by overriding default styles.

## TypeScript

YaYaw Table is fully typed with TypeScript. Declaration files are included automatically.

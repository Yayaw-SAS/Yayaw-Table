# Installation

Install YaYaw Table in your React project using your preferred package manager.

## Package Manager

```bash title="Using Bun (recommended)"
bun add yayaw-table
```

```bash title="Using npm"
npm install yayaw-table
```

```bash title="Using pnpm"
pnpm add yayaw-table
```

## Peer Dependencies

YaYaw Table depends on the following peer dependencies:

- `react` (^18.0.0)
- `react-dom` (^18.0.0)
- `@tanstack/react-table` (^8.0.0)
- `@tanstack/react-query` (^5.0.0)
- `jotai` (^2.0.0)

Make sure these are installed in your project.

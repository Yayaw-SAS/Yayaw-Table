# Installation

You can install Yayaw Table in two ways: via the **Shadcn CLI** (code copied into your project, no npm package) or via **npm** (package dependency).

## Option 1: Shadcn CLI (recommended if you use Shadcn)

The project ships a [Shadcn registry](https://ui.shadcn.com/docs/registry): all table code is added into your repo, and the CLI installs the Shadcn components we depend on (table, button, input, etc.) once — no duplication.

**Prerequisites:** a project already set up with [Shadcn UI](https://ui.shadcn.com/docs/installation) (`npx shadcn@latest init`).

From your project root:

```bash
npx shadcn@latest add https://table.yayaw.eu/r/yayaw-table.json
```

**With a configured registry:** if your project has the Yayaw registry in `components.json` (namespace `@yayaw`), you can run:

```bash
npx shadcn@latest add @yayaw/yayaw-table
```

_(Replace the URL with your docs/deploy URL if you self-host; the registry is built in CI and served from `/r/`.)_

The CLI will:

- Add any missing Shadcn components (table, button, dialog, etc.) to the path defined by your **`ui` alias**
- Copy the full Yayaw Table code (and its small ui-custom pieces) into your project under `ui/yayaw-table/` (relative to that same base)
- Install the required npm dependencies (e.g. `@tanstack/react-table`, `jotai`, `lucide-react`)

**Install path:** The Shadcn CLI uses the `ui` alias from your project’s `components.json` (`aliases.ui`). To have Shadcn components and yayaw-table under `@/components/ui` (and yayaw-table at `@/components/ui/yayaw-table`), set:

```json
"aliases": {
  "ui": "@/components/ui",
  ...
}
```

If the CLI previously installed into `@/ui/` or `@/ui/shadcn`, change this alias to `@/components/ui` and run the add command again so new installs go to the right place.

Then use the table from the copied code:

```tsx
import { DataTable } from "@/components/ui/yayaw-table";

export const MyTable = () => <DataTable tableType="products" />;
```

No `yayaw-table` package: you own and can edit the code locally.

## Option 2: Package manager (npm package)

Install the published package and use it as a dependency.

```bash title="Using npm"
npm install yayaw-table
```

```bash title="Using Bun (recommended)"
bun add yayaw-table
```

```bash title="Using pnpm"
pnpm add yayaw-table
```

### Peer dependencies

- `react` (^18 or ^19)
- `react-dom` (^18 or ^19)
- `@tanstack/react-table` (^8)
- `@tanstack/react-query` (^5) – used for data fetching and cache
- `nuqs` (^2) – used for URL state (sort, filters, pagination in the URL). For Next.js App Router use `nuqs/adapters/next/app` and add **NuqsAdapter** in your root layout; see [URL state (Nuqs)](/docs/url-state).
- `jotai` (^2) – used internally for table and UI state
- `jotai-family` (^1) – atom families used by internal state modules

### First usage

You must pass at least **getTableConfig** and **getTableActions** so the table has columns and a data source. Example:

```tsx
import { DataTable } from "yayaw-table";
import { getTableConfig, getTableActions } from "./table-config";

export const MyTable = () => (
  <DataTable
    tableType="products"
    getTableConfig={getTableConfig}
    getTableActions={getTableActions}
  />
);
```

For Next.js with URL state, add **NuqsAdapter** in `app/layout.tsx` and optionally **QueryClientProvider**. See [Provider & Setup](/docs/setup) and [URL state (Nuqs)](/docs/url-state).

## CSS / Tailwind

The table uses Tailwind CSS. Ensure Tailwind is set up in your project (or use your own classes to override default styles).

## TypeScript

Yayaw Table is fully typed; declaration files are included with both installation methods.

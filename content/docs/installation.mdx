# Installation

You can install Yayaw Table in two ways: via the **Shadcn CLI** (code copied into your project, no npm package) or via **npm** (package dependency).

## Option 1: Shadcn CLI (recommended if you use Shadcn)

The project ships a [Shadcn registry](https://ui.shadcn.com/docs/registry): all table code is added into your repo, and the CLI installs the Shadcn components we depend on (table, button, input, etc.) once — no duplication.

**Prerequisites:** a project already set up with [Shadcn UI](https://ui.shadcn.com/docs/installation) (`npx shadcn@latest init`).

From your project root:

```bash
npx shadcn@latest add https://yayaw-table.vercel.app/r/yayaw-table.json
```

_(Replace the URL with your docs/deploy URL if you self-host; the registry is built in CI and served from `/r/`.)_

The CLI will:

- Add any missing Shadcn components (table, button, dialog, etc.) to `@/components/ui`
- Copy the full Yayaw Table code (and its small ui-custom pieces) into your project (e.g. under `components/yayaw-table/`)
- Install the required npm dependencies (e.g. `@tanstack/react-table`, `jotai`, `lucide-react`)

Then use the table from the copied code:

```tsx
import { DataTable } from "@/components/yayaw-table";

export const MyTable = () => <DataTable tableType="products" />;
```

No `yayaw-table` package: you own and can edit the code locally.

## Option 2: Package manager (npm package)

Install the published package and use it as a dependency.

```bash title="Using npm"
npm install yayaw-table
```

```bash title="Using Bun (recommended)"
bun add yayaw-table
```

```bash title="Using pnpm"
pnpm add yayaw-table
```

### Peer dependencies

- `react` (^18 or ^19)
- `react-dom` (^18 or ^19)
- `@tanstack/react-table` (^8)
- `jotai` (^2) [optional]
- `@tanstack/react-query` (^5) [optional]

### First usage

```tsx
import { DataTable } from "yayaw-table";

export const MyTable = () => <DataTable tableType="products" />;
```

## CSS / Tailwind

The table uses Tailwind CSS. Ensure Tailwind is set up in your project (or use your own classes to override default styles).

## TypeScript

Yayaw Table is fully typed; declaration files are included with both installation methods.

# Ultra Simple API

L'API ultra-simple de YaYaw Table vous permet de créer des tables complètes avec **une seule config** et **zéro boilerplate**.

## Concept

```tsx
// 1. Une config unifiée
const config = {
  id: 'products',
  name: 'Products Management',
  columns: [...],
  fetchData: async (params) => { ... }
};

// 2. Un composant simple
<UltraSimpleTable config={config} />

// C'est tout ! 🎉
```

## Configuration complète

```tsx
import { UltraSimpleTable } from 'yayaw-table';

const config = {
  // Métadonnées
  id: 'products',
  name: 'Products Management',
  description: 'Table ultra-simple avec toutes les fonctionnalités',
  
  // Colonnes avec types automatiques
  columns: [
    { id: 'name', type: 'text', header: 'Product Name' },
    { id: 'brand', type: 'tag', header: 'Brand' },
    { id: 'category', type: 'tag', header: 'Category' },
    { id: 'price', type: 'number', header: 'Price' },
    { id: 'status', type: 'tag', header: 'Status' },
    { id: 'createdAt', type: 'date', header: 'Created' },
    { id: 'isActive', type: 'boolean', header: 'Active' },
  ],
  
  // Fonction de fetch des données
  fetchData: async (params) => {
    const response = await fetch('/api/products', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        page: params.page,
        limit: params.pageSize,
        sort: params.sorting,
        // params.grouping est disponible mais optionnel
      })
    });
    
    const result = await response.json();
    
    return {
      data: result.data,
      pageCount: result.meta.pageCount,
      totalCount: result.meta.totalCount,
    };
  }
};

export const ProductsTable = () => (
  <UltraSimpleTable config={config} />
);
```

## Types de colonnes

Chaque colonne a un `type` qui détermine automatiquement :
- L'icône affichée
- Le comportement de tri
- Le rendu de la cellule

```tsx
const columns = [
  { id: 'name', type: 'text', header: 'Name' },        // 📝 Icône Text
  { id: 'brand', type: 'tag', header: 'Brand' },       // 🏷️ Icône Tag
  { id: 'price', type: 'number', header: 'Price' },    // # Icône Hash
  { id: 'active', type: 'boolean', header: 'Active' }, // ⚡ Icône Toggle
  { id: 'date', type: 'date', header: 'Created' },     // 📅 Icône Calendar
];
```

## Fonctionnalités incluses

### Grouping automatique
- Boutons "Group by Brand" et "Group by Category" générés automatiquement
- Expand/collapse des groupes
- Compteurs de lignes par groupe
- Icônes par type de colonne dans les headers de groupe

### Pagination
- Navigation Previous/Next
- Affichage des compteurs (ex: "Showing 1 to 10 of 100 results")
- **Pas de Select problématique** - évite les boucles infinies

### Tri
- Tri automatique sur toutes les colonnes
- Headers cliquables
- Indicateurs visuels de tri

### Performance
- TanStack Table pur - performance optimale
- Pas de providers complexes
- Pas de re-renders inutiles
- SSR-friendly

## Exemples de fetchData

### Avec server actions
```tsx
import { productActions } from './actions';

const config = {
  // ...
  fetchData: async (params) => {
    const result = await productActions.list({
      page: params.page,
      limit: params.pageSize,
      orderBy: params.sorting,
    });
    
    return {
      data: result.data as Record<string, unknown>[],
      pageCount: result.meta?.pageCount || 1,
      totalCount: result.meta?.totalCount || 0,
    };
  }
};
```

### Avec API REST
```tsx
const config = {
  // ...
  fetchData: async (params) => {
    const url = new URL('/api/products', window.location.origin);
    url.searchParams.set('page', params.page.toString());
    url.searchParams.set('limit', params.pageSize.toString());
    
    if (params.sorting.length > 0) {
      url.searchParams.set('sort', JSON.stringify(params.sorting));
    }
    
    const response = await fetch(url);
    const result = await response.json();
    
    return {
      data: result.data,
      pageCount: Math.ceil(result.total / params.pageSize),
      totalCount: result.total,
    };
  }
};
```

### Avec GraphQL
```tsx
import { gql, request } from 'graphql-request';

const GET_PRODUCTS = gql`
  query GetProducts($page: Int!, $limit: Int!, $sort: [SortInput!]) {
    products(page: $page, limit: $limit, sort: $sort) {
      data {
        id
        name
        price
        status
      }
      meta {
        pageCount
        totalCount
      }
    }
  }
`;

const config = {
  // ...
  fetchData: async (params) => {
    const result = await request('/graphql', GET_PRODUCTS, {
      page: params.page,
      limit: params.pageSize,
      sort: params.sorting,
    });
    
    return {
      data: result.products.data,
      pageCount: result.products.meta.pageCount,
      totalCount: result.products.meta.totalCount,
    };
  }
};
```

## Migration depuis l'ancienne API

### Avant (95 lignes)
```tsx
// table-config.ts (30 lignes)
export const getTableConfig = () => ({ ... });

// columns-config.ts (40 lignes)  
export const getColumnsConfig = () => ({ ... });

// form-config.ts (25 lignes)
export const getFormConfig = () => ({ ... });

// Usage complexe
<TableProvider 
  getTableConfig={getTableConfig}
  getColumnsConfig={getColumnsConfig}
  getFormConfig={getFormConfig}
  translations={translations}
>
  <DataTableUIProvider columnsConfig={...} tableConfig={...}>
    <DataTable 
      tableType="products"
      columnTypeMapping={{...}}
      enableAdvancedFilters={true}
    />
  </DataTableUIProvider>
</TableProvider>
```

### Après (5 lignes)
```tsx
// config.ts (tout en un)
const config = { id, name, columns, fetchData };

// Usage simple
<UltraSimpleTable config={config} />
```

**95% moins de code !** 🎉

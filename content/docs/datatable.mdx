# DataTable Reference

The single entry-point component: you pass config and actions as props; it composes the provider, UI, and table logic internally. Import from `yayaw-table` (or your Shadcn copy).

```tsx
import { DataTable } from "yayaw-table";
```

For a minimal working setup you need **tableType**, **getTableConfig**, and **getTableActions**. See [Provider & Setup](/docs/setup) for the full list and Next.js layout (NuqsAdapter, QueryClientProvider).

## Props

List of available props for configuring `DataTable`.

### tableType
The identifier of your table. Used to resolve config and actions (e.g. `getTableConfig("products")`, `getTableActions("products")`).

```tsx
<DataTable tableType="products" />
```

Required: `true`

### getTableConfig
Function that returns table and column configuration for the given `tableType`. Required for the table to know columns, sort, visibility, and options. See [Configuration](/docs/configuration) and [Setup](/docs/setup).

Type: `(tableType: string) => Config | undefined`

### getTableActions
Function that returns actions (list, create, update, delete, bulk, etc.) for the given `tableType`. **list** is required for server-driven data. Can be Server Actions in Next.js. See [Actions](/docs/actions) and [Server-side & Server Actions](/docs/server-actions).

Type: `(tableType: string) => TableActions | undefined`

### getFormConfig
Function that returns form field definitions for create/edit and bulk edit dialogs. Optional but needed for forms.

Type: `(formType: string) => FormConfig | undefined`

### queryClient
TanStack Query client instance. Optional; the table can create one if not provided. Recommended to pass one when using a single app-wide client.

Type: `QueryClient`

### className
Additional class names applied to the root wrapper.

Type: `string` | Default: `undefined`

### loadingOverlay
Custom loading overlay to display while data is loading.

Type: `React.ReactNode` | Default: internal spinner overlay

```tsx
<DataTable tableType="products" loadingOverlay={<MySpinner />} />
```

### onRowSelectionChange
Callback fired when selected rows change.

Type: `(rows: Row<Record<string, unknown>>[]) => void` | Default: `undefined`

### onBulkEdit
Handle bulk edit of selected rows.

Type: `(rows: Row<Record<string, unknown>>[]) => void` | Default: uses provider `update`

### onBulkDelete
Handle bulk deletion of selected rows.

Type: `(rows: Row<Record<string, unknown>>[]) => void` | Default: uses provider `delete`

### onBulkCopy
Handle bulk duplication of selected rows.

Type: `(rows: Row<Record<string, unknown>>[]) => void` | Default: uses provider `duplicate`

### enableAdvancedFilters
Enable advanced filters UI when available in your configuration.

Type: `boolean` | Default: `false`

### columnTypeMapping
Map dynamic backend types to internal column renderer types.

Type: `Record<string, 'text' | 'number' | 'date' | 'option' | 'multiOption'>` | Default: `{}`

## Usage

```tsx
<DataTable
  tableType="products"
  loadingOverlay={<MySpinner />}
  onRowSelectionChange={(rows) => console.log(rows)}
  onBulkDelete={(rows) => console.log("delete", rows.length)}
/>
```

# YaYaw Table Documentation

YaYaw Table est une librairie de composants data table ultra-simple pour React. **Une config, un composant, zéro boilerplate !**

## 🚀 Quick Start

```bash
npm install yayaw-table
# ou
bun add yayaw-table
```

### API Ultra-Simple

```tsx
import { UltraSimpleTable } from 'yayaw-table'

const config = {
  id: 'products',
  name: 'Products Management',
  description: 'Table ultra-simple avec grouping, pagination et tri',
  
  columns: [
    { id: 'name', type: 'text', header: 'Product Name' },
    { id: 'brand', type: 'tag', header: 'Brand' },
    { id: 'price', type: 'number', header: 'Price' },
    { id: 'status', type: 'tag', header: 'Status' },
  ],
  
  fetchData: async (params) => {
    const result = await fetch('/api/products', {
      method: 'POST',
      body: JSON.stringify(params)
    });
    return result.json();
  }
};

export const MyTable = () => (
  <UltraSimpleTable config={config} />
);
```

**C'est tout !** 🎉

## ✅ Avantages

- **95% moins de code** - Une seule config
- **Zero providers** - Plus de setup complexe

- **Types intégrés** - Icônes automatiques
- **SSR-friendly** - Pas d'hydration errors

## 📖 API Reference

### UltraSimpleConfig

```tsx
interface UltraSimpleConfig {
  id: string;
  name: string;
  description?: string;
  
  columns: Array<{
    id: string;
    type: 'text' | 'tag' | 'number' | 'boolean' | 'date';
    header: string;
  }>;
  
  fetchData: (params: {
    page: number;
    pageSize: number;
    sorting: SortingState;
    grouping: GroupingState;
  }) => Promise<{
    data: Record<string, unknown>[];
    pageCount: number;
    totalCount: number;
  }>;
}
```

### Exemple fetchData
```tsx
fetchData: async (params) => {
  const result = await productActions.list({
    page: params.page,
    limit: params.pageSize,
    orderBy: params.sorting,
  });
  
  return {
    data: result.data as Record<string, unknown>[],
    pageCount: result.meta?.pageCount || 1,
    totalCount: result.meta?.totalCount || 0,
  };
}
```
